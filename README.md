This project is an interactive Hotel Booking Cancellation Analysis Dashboard created entirely in Microsoft Excel.
The dashboard provides insights into hotel booking trends, cancellations, guest types, room preferences, and monthly performance using pivot tables, charts, and slicers.
The objective of this project is to analyze booking behavior and identify patterns in cancellations to support better decision-making for hotel management.
🛠 Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning & Formatting
Dashboard Design & Visualization
📂 Dataset Details
The dataset contains hotel booking records including:
Arrival Year
Hotel Type (City / Resort)
Guest Type (Couples, Family, etc.)
Room Type (Desired / Undesired)
Booking Status (Canceled / Not Canceled)
Monthly Booking Data
Total Guests

📊 Dashboard Features
✔ Year-wise filter using slicer
✔ Total Bookings KPI
✔ Total Cancellation KPI
✔ Hotel Type Distribution (City vs Resort)
✔ Guest Type Analysis
✔ Room Type Preference Analysis
✔ Monthly Booking & Cancellation Trends
✔ Clean dark-themed professional dashboard design

📈 Key Insights
Higher cancellations observed in specific guest categories.
City hotels receive more bookings compared to resort hotels.
Certain months show peak booking and cancellation rates.
Undesired room types have different cancellation patterns.
